# Banyu AI Studio · 伴语 AI

全本地虚拟主播工作室，当前采用一二和布布的程序化 3D 演示形象，角色来源与授权说明见 [素材记录](docs/ASSETS.md)。

3D 虚拟主播本地演示：模拟文字弹幕、中文语音、音量驱动嘴型、预设表情动作、输入/输出审核、人工接管及急停。

## 在这台电脑运行

双击 **Start-Studio.cmd**，浏览器访问 **http://127.0.0.1:8765**。

1. 在角色预览中点击「启用声音与角色」。浏览器需要一次点击才能播放声音。
2. 点击「恢复回答」。默认启动时始终暂停。
3. 输入昵称和弹幕，点击「发送弹幕」。
4. 待审内容可丢弃，或编辑为安全回复后重新审核；没有跳过审核的按钮。
5. 点击「停止发声与清空队列」可停止播出；恢复必须由导播手动操作。

「切换独立展示页」会暂停当前播出。新展示页点击启用声音后接管播放权，再在导播台恢复回答。一次只授权一个展示页播放，自动重连不会抢占；直接打开 `/display` 可用作独立画面。

## 首次安装或迁移

需要 Windows、Node.js 22+、Python 3.12。首次准备需要联网，运行阶段不请求云服务。

```powershell
./Setup.ps1
# 或指定 Python 3.12 可执行文件
./Setup.ps1 -Python 'C:/path/to/python.exe'
./Start-Studio.ps1
```

若 PowerShell 执行策略限制脚本，可使用 `powershell -NoProfile -ExecutionPolicy Bypass -File ./Setup.ps1`；这仅对该次启动生效。

依赖使用项目虚拟环境 `.venv312`，前端使用 npm 锁文件；便携 Ollama 在 `.runtime/ollama`，模型在 `models`。本机安装复用了已有 Python 3.12 环境中的 PyTorch，未修改其已安装包；在新电脑上 Setup 会建立独立环境。当前环境清单见 `docs/python-environment.txt`。

应用端口为 **8765**；项目 Ollama 使用 **11435**，与默认 11434 服务分开。默认只绑定回环地址；启用内网配置后，导播台可通过内网地址访问，Ollama 仍只监听本机。

内网配置保存在被 Git 忽略的 `.runtime/lan.json`，包含内网 IPv4 地址和随机访问令牌。内网访问必须使用 `http://内网地址:8765/?access=令牌`；登录后地址栏会移除令牌，后续请求使用 HttpOnly 会话 Cookie。匿名内网请求不能读取页面、会话、对话记录或音频。主机 IP 地址变化时需更新配置；这是内网演示入口，不用于公网发布。

如下载中断，可重跑 Setup；也可用 `python scripts/prepare.py --component qwen` 从官方仓库下载并校验模型。下载器验证长度，支持分段续传；Qwen blob 逐个核对官方 SHA-256，Ollama 包核对 GitHub 发布摘要。

## 人设、规则和素材

- 人设位于 `backend/safety.py` 的 `HOST`，当前一二主讲、布布陪伴，面向公众与未成年人。默认回答最多 360 字符；明确要求字数时支持单次约 1200 字，超出时说明限制并建议分章节。
- 当前使用本地 `qwen3:4b-instruct-2507-q4_K_M`。过滤无意义历史，对复读、字数不足等可检测问题重试一次，仍不合格转人工；这不能保证事实正确或全面理解问题。
- 完整回答先通过输出审核，再按每段最多 150 字符合成播放。每段使用独立播放编号，急停会作废剩余段落；人工编辑上限为 1600 字符，仍须审核。
- 对话由 `backend/conversation.py` 构建标准多轮消息，并注入北京时间与实际模型身份。最后一条用户消息始终为当前问题；日期不由模型自行猜测。`scripts/check_dialogue.py` 验证真实模型的对题性及连续追问。
- 可编辑规则位于 `config/rules.json`，每条包含 `id/category/decision/pattern`。`decision` 只能为 `refuse` 或 `review`。在「风控与运行」重载，系统会暂停，错误规则不会导致继续自动播出。
- 规则处理字符归一化、常见拆分与预设谐音；不声称覆盖所有谐音或绕过方式。未直接匹配的内容还要经过本地语义审核。
- 自伤求助转人工，支持性回复可重新审核；不能播出伤害方法。科普与预防类问题需要结合上下文判断，不能靠敏感词简单定性。
- 当前形象由 `frontend/src/bears.ts` 的几何与材质实时构建，是一二和布布的程序化3D演示版本，不是官方模型；一二使用现有的一路语音，布布配合表情动作。参见 `docs/ASSETS.md`。
- `frontend/public/avatar.vrm` 保留为此前的 pixiv 样例资源，当前页面不再加载；记录见 `docs/avatar-license.json`。调整形象后需重新构建前端。

## 风控边界

所有观众输入都是不可信数据。程序先检查昵称与弹幕，再生成完整回答，检查回答后才合成和播出。模型没有工具调用入口，动作仅能使用 `idle/nod/wave/smile/confused` 五个编号。

审核无法判断、返回格式错误、超时、对话或语音服务失败均进入待审。明确违规直接拦截。审核使用与对话相同的模型，独立调用不代表独立安全保证。规则和模型审核都会有误判及漏判，当前测试不代表可无人值守公开直播。

急停通过任务代次作废所有处理中和待播任务，撤销音频访问，并通知展示页停止。展示页断开会触发后端暂停；展示页也有心跳看门狗，在超过 6 秒未收到服务器消息时本地停播。断网无法保证远程指令瞬间送达。

本地后端默认禁止外网 socket 连接；模型及语音只读取本地文件。Ollama 启动设置 `OLLAMA_NO_CLOUD=1`。未进行操作系统级全机断网；测试使用浏览器外部请求阻断、后端 socket 阻断和进程网络观测验证本地数据流。

管理操作受本机会话 Cookie、Origin/Host 检查及自定义请求头约束。它是单机应用，不提供多用户登录，也不隔离同一电脑上的恶意本地程序。

## 数据与测试

普通对话只在进程内保留最近有限记录；模型上下文只保留最近四次已播出交流的短截取片段，不保存长期个人记忆。默认日志只记录分类、耗时和时间；模型分类采用固定枚举，不能把输入原文塞进分类日志。开启「原文调试」才会写 `data/debug.jsonl`；「清除日志」同时关闭调试。

```powershell
./.venv312/Scripts/python -m pytest tests -q
cd frontend
npm run build
cd ..
node scripts/browser-check.mjs
./.venv312/Scripts/python scripts/check_dialogue.py
node scripts/acceptance.mjs
node scripts/benchmark.mjs --seconds 1800
```

浏览器检查和基准测试需要本机 Chrome 及已启动的服务；基准会真正生成并播放语音、消耗本机资源，并在结束后急停。报告写入 `docs/verification`。完整实测状态见 `docs/TEST-REPORT.md`。

首版不包含真实平台弹幕接入、麦克风、声音克隆、主动联网、电脑控制和长期记忆。
