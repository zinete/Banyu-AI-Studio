- 已查看全部折叠线截图和整页截图；文字没有横向溢出，手机按角色、弹幕输入、待审、记录顺序排列。

- 主问题由真实角色状态回答；数据均来自单一后端状态，零计数和缺失数据分别显示 0 与破折号；按钮都可使用键盘。

## 一二和布布形象更新

- 保留既有 True-black flat 控制台方向与布局，没有重抽方向。舞台主体替换为两只程序化3D角色，白色一二主讲，棕色布布陪伴。
- 根据公开插画核对深色圆耳、豆豆眼、粉色/暖黄色腮红和小嘴；采用柔和圆头、短四肢与哑光材质。它是项目实现的简化3D演示版，不是官方模型。
- 看图修正了初版偏方的头型以及腮红与曲面相交的问题；舞台截图与手机截图均已实际查看。
- 使用单一路径的真实音频能量驱动一二嘴型；布布不复制嘴型，配合预设表情和动作。测试覆盖挥手、微笑、疑惑、减少动态效果和急停冻结。
